📱 iPhone-Widgets

So geht's:
1. App „Scriptable“ (kostenlos) installieren.
2. Hier „Widget-Script kopieren“ tippen.
3. In Scriptable oben rechts ＋ → einfügen → oben den Namen „Life Planner“ geben → Fertig.
4. Home-Bildschirm lange drücken → ＋ → Scriptable → Größe wählen → Widget hinzufügen.
5. Widget lange drücken → „Widget bearbeiten“ → Script: Life Planner, Parameter: heute, gewohnheiten, kalender, aufgaben, vers oder fortschritt.

👟 Schritte

Mit einem Kurzbefehl schickt dein iPhone die Schritte aus der Health-App mit einem Tipp in den Planner:
  1. Öffne die App Kurzbefehle → + → Name: „Schritte → Planner“.
  2. Aktion Health-Samples suchen: Typ Schritte, Startdatum ist heute, gruppieren nach Tag.
  3. Aktion Statistik berechnen → Summe, dann Zahl runden (auf Einerstellen).
  4. Aktion URL:
    (statt ZAHL die gerundete Zahl als Variable einsetzen)
  5. Aktion URLs öffnen. Fertig – optional als Automation jeden Abend.
Die App trägt die Schritte dann automatisch für heute ein.
